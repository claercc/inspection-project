# 设备工作台：第一步

本次只整理前端设备模块与运行入口，不修改设备协议和后端执行语义。

- 阅读入口：`web/src/features/device/DevicePage.vue`。
- 页面调用：`DevicePage → useDevice → api → 原有 HTTP/SSE 接口`。
- 组件集中在设备模块内；格式化与状态文案继续共用。
- 主区域保留指标、曲线、控制、命令记录。原始数据来源和通信诊断按需打开。
- 摄像头、采集记录暂不可操作；不提供假的视频、抓拍结果或历史数据。
- 目前只有一个可用页面，尚未增加路由依赖。实际接入第二个页面时再引入路由。
- 模拟器与机器人相关的内部协议名称暂保留，避免单纯改名影响既有链路；旧场景组件暂留作迁移参考，不再被页面引用。
- 最新数据、命令记录仍是内存数据；数据库持久化没有在这一步实现。

运行：`powershell -ExecutionPolicy Bypass -File scripts/start.ps1 -SkipBuild`，访问 http://127.0.0.1:8088 。首次需要先执行 `scripts/build.ps1`。

后续顺序：拆分后端配置/消息接入与业务协调 → 补记录持久化 → 根据实际摄像头型号接入预览和抓拍。每一步单独验证后再继续。
